Solid-gas thermodynamics

Can this gas reduce this oxide?

Two tools for the same question, answered two ways. Both run entirely in the browser — no server, no external requests, nothing stored. The thermodynamic data is compiled into each page from the Python package that generated it.

gibbs_min

Oxide reduction under a reacting gas

Full-composition Gibbs energy minimisation over gas and condensed phases at fixed elemental balance. The phase assemblage is an output, not an input.

  • Ti–O (rutile + Magnéli series) and Ce–O (ceria)
  • CO2/H2 = 1:1 feed, 500–1500 °C
  • Verification tab: the same condition solved by an independent route, difference shown
  • Coefficients, element balance, solver state and the full derivation on the page
Open the solver
oxygen potential

TiOx oxygen-potential dashboard

The fast route, swept continuously. Equilibrates the C–H–O gas, reads its oxygen potential, and compares it against every phase boundary in the series.

  • RWGS, pure H2, pure CH4, sealed N2
  • Continuous temperature sweep with the boundaries drawn
  • Waldner or NIST dataset, series depth adjustable
  • Reported values are read from results.json, computed by minimisation

Which one answers the question. The two routes are mathematically equivalent for this system and they agree wherever both have been run — the minimisation's gas lands on the independently computed phase boundary to within 4×10−5 kJ per mol O. They are kept apart anyway: agreement everywhere is exactly what makes a value from the wrong route impossible to catch by reading it, so every reported number carries the method that produced it, and a test refuses any that does not say gibbs_min.
Gases: NIST-JANAF 4th ed. (Chase, 1998). Ti–O condensed phases: Waldner & Eriksson, Calphad 23 (1999) 189–218. Ce–O: NIST-JANAF. Source: robin-yk/Solid-gas-thermosolver.
