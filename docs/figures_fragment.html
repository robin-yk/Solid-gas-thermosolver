Manuscript figure plates

Plates for the gas-solid equilibrium solver and the defect statistical-mechanics solver, drawn to print size from frozen solver output. Every value on this page is one the code produced; no number is typed twice.

Placing a plate in a manuscript. Copy SVG puts the vector source on the clipboard; save it as a file ending in .svg and place that file, and the artwork stays sharp at any size with type at a true print size. Render 600 dpi rasterises the same artwork into a canvas on this page; right-click it and choose Save image as for a PNG. Neither route can start a download itself: a published page cannot write to disk. Captions sit below each plate as text rather than inside the artwork, so they can be pasted in as captions and picked up by cross-references.

Colour and type conventions

One hue is assigned to one physical role and used the same way in every plate. Structure is not coloured: axes, boundaries and anything held fixed are neutral grey, so a hue appears only where it names something. The set is Okabe-Ito, so it survives colour-blind readers and greyscale printing, and the roles are also separated by position and line style. Type is sans-serif throughout and never below the journal floor at printed size.

Every panel is a closed rectangle, not an open L. Ticks point into the panel, tick labels appear on the bottom and left only, and there is no grid. Data curves carry one stroke weight and spines, ticks and guides another, so weight alone says whether a line is a measurement or a rule. Each plate is exported at its declared column width as print SVG and as a 600 dpi raster by node scripts/export_figures.js.
